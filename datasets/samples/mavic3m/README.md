# One Mavic 3M capture

Put a single shutter group here, and the calibration-panel photo if the download includes one.

Expected names from this camera:

- `*_D.JPG` — the RGB photo
- `*_MS_G.TIF`, `*_MS_R.TIF`, `*_MS_RE.TIF`, `*_MS_NIR.TIF` — green, red, red edge, near infrared

Leave the rest of the flight on your computer. This folder is the only image path Git will accept.
